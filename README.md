**Bash File Manager**

**Description**

This is a simple file manager written in Bash. It allows users to manage files and directories directly from the terminal using an easy menu.

**Features**

* Create and delete files and directories

* Rename, copy, and move files

* Change and show current directory

* Display files, including hidden files

**How to Run**

* Open the terminal.

* Run chmod +x manager.sh

* Start with ./manager.sh

**Usage**

Enter your name, choose an option from the menu, and follow the instructions. Press 0 to exit.
